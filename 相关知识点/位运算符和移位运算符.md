## 位运算符和移位运算符
### 1. 位运算符
位运算符是对整数的二进制位进行操作。位运算符只适用于整数类型（byte、short、int、long）和字符类型（char）。

#### 1.1 按位与运算符（`&`）
按位与运算符（`&`）对两个整数的二进制位进行与运算。只有当两个二进制位都为1时，结果才为1，否则结果为0。

```cpp
    int a = 10;
    int b = 20;
    int c = a & b;
    cout << c << endl;
    return 0;
```
输出结果为0。

#### 1.2 按位或运算符（`|`）
按位或运算符（`|`）对两个整数的二进制位进行或运算。只要两个二进制位中有一个为1，结果就为1，否则结果为0。

```cpp
    int a = 10;
    int b = 20;
    int c = a | b;
    cout << c << endl;
    return 0;
```
输出结果为30。

#### 1.3 按位异或运算符（`^`）
按位异或运算符（`^`）对两个整数的二进制位进行异或运算。如果两个二进制位不同，结果就为1，否则结果为0。

```cpp
    int a = 10;
    int b = 20;
    int c = a ^ b;
    cout << c << endl;
    return 0;
```
输出结果为20。
