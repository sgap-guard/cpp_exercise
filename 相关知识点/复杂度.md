# C++ 时间复杂度与空间复杂度学习笔记

## 一、为什么需要复杂度分析

衡量算法优劣，不能只看代码跑得快不快（受机器、编译器、数据规模影响），而要看**算法执行效率随数据规模增长的变化趋势**。这就是复杂度分析的意义。

- **时间复杂度**：描述运行时间随输入规模 n 的增长趋势
- **空间复杂度**：描述额外内存占用随输入规模 n 的增长趋势

## 二、时间复杂度

### 2.1 大 O 表示法

**定义**：若存在正常数 c 和 n₀，使得当 n ≥ n₀ 时，T(n) ≤ c·f(n)，则记 T(n) = O(f(n))。

**核心思想**：只保留最高阶项，去掉系数和低阶项。

```
T(n) = 3n² + 5n + 100  →  O(n²)
T(n) = 2n + 10         →  O(n)
T(n) = 1000            →  O(1)
```

### 2.2 常见复杂度量级（从快到慢）

| 量级 | 名称 | 典型场景 |
|------|------|----------|
| `O(1)` | 常数阶 | 数组随机访问、哈希查找 |
| `O(log n)` | 对数阶 | 二分查找、平衡树操作 |
| `O(n)` | 线性阶 | 一次遍历 |
| `O(n log n)` | 线性对数阶 | 归并排序、快速排序（平均） |
| `O(n²)` | 平方阶 | 双重循环、冒泡排序 |
| `O(n³)` | 立方阶 | 三重循环、Floyd 算法 |
| `O(2ⁿ)` | 指数阶 | 暴力子集枚举 |
| `O(n!)` | 阶乘阶 | 全排列暴力 |

**增长对比**（n = 1000）：
```
O(1)      ≈ 1
O(log n)  ≈ 10
O(n)      ≈ 1000
O(n log n)≈ 10000
O(n²)     ≈ 1,000,000
O(2ⁿ)     ≈ 天文数字
```

### 2.3 计算方法

**规则一：只看最高阶**
```cpp
// O(n² + n) = O(n²)
for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++)
        sum += i * j;
```

**规则二：加法法则（顺序执行取最大）**
```cpp
// O(n) + O(n²) = O(n²)
void func(int n) {
    for (int i = 0; i < n; i++) { /* O(n) */ }
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++) { /* O(n²) */ }
}
```

**规则三：乘法法则（嵌套相乘）**
```cpp
// O(n * m)
for (int i = 0; i < n; i++)
    for (int j = 0; j < m; j++)
        sum += i * j;
```

### 2.4 经典代码示例

**O(1)**
```cpp
int getFirst(vector<int>& v) {
    return v[0];           // 与 n 无关
}
```

**O(log n)** —— 循环变量乘除
```cpp
int i = 1;
while (i < n) {
    i *= 2;                // 执行 log₂n 次
}
```

**O(n)** —— 线性遍历
```cpp
for (int i = 0; i < n; i++) {
    cout << arr[i];
}
```

**O(n log n)** —— 线性嵌套对数
```cpp
for (int i = 0; i < n; i++) {     // n 次
    int j = 1;
    while (j < n) {               // log n 次
        j *= 2;
    }
}
```

**O(n²)**
```cpp
for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++)
        sum += i * j;
```

**O(√n)**
```cpp
for (int i = 1; i * i <= n; i++) {   // 试除法判断质数
    if (n % i == 0) return false;
}
```

### 2.5 递归的时间复杂度

**方法：画递归树 / 写递推式**

**示例1：斐波那契（朴素递归）**
```cpp
int fib(int n) {
    if (n <= 1) return n;
    return fib(n - 1) + fib(n - 2);
}
```
递推式：T(n) = T(n-1) + T(n-2) + O(1) → **O(2ⁿ)**

**示例2：二分查找**
```cpp
int binarySearch(vector<int>& v, int target) {
    int l = 0, r = v.size() - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (v[mid] == target) return mid;
        else if (v[mid] < target) l = mid + 1;
        else r = mid - 1;
    }
    return -1;
}
```
每次规模减半：T(n) = T(n/2) + O(1) → **O(log n)**

**示例3：归并排序**
```cpp
// T(n) = 2T(n/2) + O(n)  →  O(n log n)
```

**主定理（Master Theorem）** 快速判断 T(n) = aT(n/b) + f(n)：
- 若 $f(n) = O(n^(log_b a - ε))$ → $T(n) = Θ(n^(log_b a))$
- 若 $f(n) = Θ(n^(log_b a))$ → $T(n) = Θ(n^(log_b a) · log n)$
- 若 $f(n) = Ω(n^(log_b a + ε))$ → $T(n) = Θ(f(n))$

### 2.6 最好、最坏、平均复杂度

以快速排序为例：
- **最好**：每次均分 → O(n log n)
- **最坏**：每次取到极值 → O(n²)
- **平均**：O(n log n)

以线性查找为例：
```cpp
int find(vector<int>& v, int x) {
    for (int i = 0; i < v.size(); i++)
        if (v[i] == x) return i;
    return -1;
}
```
- 最好 O(1)，最坏 O(n)，平均 O(n)

## 三、空间复杂度

### 3.1 定义

算法**额外**占用的存储空间随 n 的增长趋势，**不包括输入数据本身**。

```
S(n) = O(f(n))
```

### 3.2 常见量级

| 量级 | 说明 | 示例 |
|------|------|------|
| O(1) | 常量空间 | 交换两个变量、迭代 |
| O(n) | 线性空间 | 一维数组、递归栈深度 n |
| O(n²) | 二维空间 | 二维数组、邻接矩阵 |
| O(log n) | 对数空间 | 二分查找递归栈 |

### 3.3 代码示例

**O(1)**
```cpp
int sum(vector<int>& v) {
    int s = 0;                 // 只用了常数个变量
    for (int x : v) s += x;
    return s;
}
```

**O(n)**
```cpp
vector<int> copy(vector<int>& v) {
    vector<int> res(v.size()); // 额外 n 个空间
    for (int i = 0; i < v.size(); i++) res[i] = v[i];
    return res;
}
```

**O(n²)**
```cpp
vector<vector<int>> matrix(n, vector<int>(n));  // n×n
```

**递归的空间复杂度 = 递归深度**
```cpp
int fact(int n) {
    if (n <= 1) return 1;
    return n * fact(n - 1);    // 递归深度 n，空间 O(n)
}
```

### 3.4 原地算法（In-place）

空间复杂度 O(1) 的算法称原地算法，如：
- 冒泡排序、插入排序、选择排序
- 堆排序
- 数组反转（双指针）

```cpp
void reverse(vector<int>& v) {
    int i = 0, j = v.size() - 1;
    while (i < j) swap(v[i++], v[j--]);   // O(1) 额外空间
}
```

## 四、时间与空间的权衡

**空间换时间**：
- 哈希表：O(n) 空间，查询从 O(n) 降到 O(1)
- 前缀和：O(n) 空间，区间求和从 O(n) 降到 O(1)
- 记忆化搜索 / DP 表：用空间避免重复计算
- 缓存、预计算

**时间换空间**：
- 压缩存储（如位图）
- 流式处理，不保存全部数据
- 重新计算代替存储

**示例对比：斐波那契**

```cpp
// 递归：时间 O(2ⁿ)，空间 O(n)
int fib1(int n) {
    if (n <= 1) return n;
    return fib1(n-1) + fib1(n-2);
}

// 记忆化：时间 O(n)，空间 O(n)
int memo[100] = {0};
int fib2(int n) {
    if (n <= 1) return n;
    if (memo[n]) return memo[n];
    return memo[n] = fib2(n-1) + fib2(n-2);
}

// 迭代滚动：时间 O(n)，空间 O(1)
int fib3(int n) {
    if (n <= 1) return n;
    int a = 0, b = 1;
    for (int i = 2; i <= n; i++) {
        int c = a + b; a = b; b = c;
    }
    return b;
}
```

## 六、分析技巧与注意事项

1. **看循环边界**：`i < n` 与 `i * i < n` 差别巨大
2. **看循环变量变化**：`i++` 是线性，`i *= 2` 是对数
3. **嵌套循环相乘，顺序循环相加取大**
4. **递归看递归树深度与每层工作量**
5. **均摊分析**：如 vector 的 push_back，单次可能 O(n)，但均摊 O(1)
6. **忽略常数但要留意实际性能**：O(n) 的算法常数可能比 O(n log n) 更大
7. **空间复杂度只算额外空间**，输入不计入
8. **递归的空间 = 递归深度 × 每层空间**
9. **区分最好/最坏/平均**，尤其快排、哈希
10. **实际工程中**：n 较小时复杂度差异不明显，n 很大时量级决定一切

## 七、速查口诀

```
常数对数线性方，指数阶乘要提防。
循环嵌套乘着看，顺序执行取最大。
递归画树写递推，主定理来快判断。
空间只算额外用，递归深度别忘算。
时空常常可互换，缓存记忆是良方。
```

## 八、练习建议

1. 分析自己写过的每一段代码的复杂度
2. 手推常见排序、查找的复杂度
3. 用递归树推导斐波那契、归并、快排
4. 尝试把一个 O(n²) 算法优化到 O(n log n) 或 O(n)
5. 在 LeetCode 上刷题时，先估算复杂度再看题解

掌握复杂度分析，是从"能写出代码"到"能写出好代码"的关键一步。
