## 基本数据类型
基本数据类型是指在C程序中使用最频繁的数据类型，包括整型、浮点型、字符型、布尔型等。

### 整型
整型是指没有小数部分的数值，包括有符号整型和无符号整型。

#### 有符号整型
有符号整型包括`int`、`short`、`long`、`long long`等类型。

#### 无符号整型
无符号整型包括`unsigned int`、`unsigned short`、`unsigned long`、`unsigned long long`等类型。

### 浮点型
浮点型是指带有小数部分的数值，包括`float`、`double`、`long double`等类型。

### 字符型
字符型是指单个字符，包括`char`类型。

## 常量
常量是指在程序运行时不能改变的变量

### 整型常量
整型常量是指没有小数部分的数值，包括十进制、八进制和十六进制三种表示方式。

#### 十进制常量
十进制常量是最常见的整型常量表示方式，直接写数字即可。

#### 八进制常量
八进制常量以0开头，后面跟0-7的数字。

#### 十六进制常量
十六进制常量以0x开头，后面跟0-9、a-f或A-F的数字。

### 浮点型常量
浮点型常量是指带有小数部分的数值，包括小数形式和指数形式两种表示方式。

#### 小数形式
小数形式直接写数字即可。

#### 指数形式
指数形式以e或E开头，后面跟指数部分。

### 字符型常量
字符型常量是指单个字符，包括普通字符和转义字符两种表示方式。

#### 普通字符
普通字符直接写字符即可。

#### 转义字符
转义字符是指在字符型常量中表示特殊含义的字符，例如换行符、回车符、制表符等。

| 转义字符 | 含义 | ASCII代码 |
| -------- | ---- | ---- |
| `\n  `     | 换行符 | 10 |
| `\r`| 回车符 |   13 |
| `\t`     | 制表符 | 9 |
| `\\`     | 反斜杠 | 92 |
| `""`     | 双引号 | 34 |
| `'`     | 单引号 | 39 |
| `\0`     | 空字符 | 0 |
| `\a`     | 响铃符 | 7 |
| `\b`     | 退格符 | 8 |
| `\f`     | 换页符 | 12 |
| `\v`     | 垂直制表符 | 11 |
| `\?`     | 问号 | 63 |
| `\xHH`     | 十六进制数 | 120 |

| `\'`     | 单引号字符 | 39 |
| `\"`     | 双引号字符 | 34 |
| `f`     | 换页符 | 12 |

### 布尔型常量
布尔型常量是指`true`和`false`两个值，用于表示逻辑真和逻辑假。

### 枚举常量
枚举常量是指由一组命名的常量组成的常量集，用于表示一组相关的常量。

### 字符串常量
字符串常量是指由多个字符组成的序列，用于表示文本。
```
"hello world"
```

### 枚举常量
枚举常量是指由一组命名的常量组成的常量集，用于表示一组相关的常量。
```
enum Color { RED, GREEN, BLUE };
```

### 宏常量
宏常量是指由`#define`指令定义的常量，用于表示一个常量值。
```
#define PI 3.1415926
```

### 总结
常量是指在程序运行时不能改变的变量，包括整型、浮点型、字符型、布尔型等。
