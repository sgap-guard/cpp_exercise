## C++条件语句
### 1. `if`语句
if语句用于根据条件执行不同的代码块。
```cpp
if (condition) {
    // 代码块1
} else {
    // 代码块2
}
```

### 2. `if`语句（多条件）
if语句可以包含多个条件，每个条件之间用`||`或`&&`运算符连接。
```cpp
if (condition1) {
    // 代码块1
} else if (condition2) {
    // 代码块2
} else {
    // 代码块3
}
```

### 3. `if`语句（嵌套）

if语句可以嵌套在其他if语句中，形成多层条件判断。
```cpp
if (condition1) {
    if (condition2) {
        // 代码块1
    } else {
        // 代码块2
    }
} else {
    // 代码块3
}
```

### 4. `switch`语句
switch语句用于根据变量的不同值执行不同的代码块。
```cpp
switch (variable) {
    case value1:
        // 代码块1
        break;
    case value2:
        // 代码块2
        break;
    default:
        // 代码块3
}
```
### 5. `switch`语句（嵌套）
switch语句可以嵌套在其他switch语句中。
```cpp
switch (variable1) {
    case value1:
        switch (variable2) {
            case value2:
                // 代码块1
                break;
            default:
                // 代码块2
        }
        break;
    default:
        // 代码块3
}
```

### 6. `switch`语句（多条件）
switch语句可以包含多个条件，每个条件之间用逗号分隔。
```cpp
switch (variable) {
    case value1:
    case value2:
        // 代码块1
        break;

}
```
### 7. `switch`语句（范围）
switch语句可以包含一个范围，表示变量的值在某个范围内。
```cpp
switch (variable) {
    case value1 ... value2:
        // 代码块1
        break;
    default:
        // 代码块2
}
```
