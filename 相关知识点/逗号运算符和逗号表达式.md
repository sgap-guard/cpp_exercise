## 逗号运算符和逗号表达式
### 逗号运算符
逗号运算符用于将两个表达式连接起来，并返回第二个表达式的值。逗号运算符的优先级非常低，因此它通常用于在需要多个表达式的位置上连接表达式。

### 逗号表达式
逗号表达式是由逗号运算符连接起来的多个表达式。逗号表达式的值是最后一个表达式的值。在逗号表达式中，每个表达式都会被求值，但是只有最后一个表达式的值会被返回。

### 示例
```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    int b = a + 5;
    cout << b << endl;
    return 0;
}
```
