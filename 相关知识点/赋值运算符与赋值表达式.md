## 赋值运算符与赋值表达式

### 赋值运算符

赋值运算符`=`用于给变量赋值，它的左边必须是一个左值，右边是一个右值。

```c
int a = 1;
int b = 2;
int c = a + b;
```

### 赋值表达式

赋值表达式`=`的返回值是赋值运算符左边的变量，即`a = b`的返回值是`a`的值。

```c
int a = 1;
int b = 2;
int c = a = b;
```

### 赋值运算符与赋值表达式的区别

赋值运算符`=`用于给变量赋值，它的左边必须是一个左值，右边是一个右值。赋值表达式`=`的返回值是赋值运算符左边的变量，即`a = b`的返回值是`a`的值。
