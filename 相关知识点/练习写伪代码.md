# 训练编写伪代码的能力

> 伪代码不是固定语法，它是**写给自己看的思路草稿**。目标：脱离编程语言细节，只描述「要做什么」，而不是「用什么语法写」。

## 一、先搞懂：伪代码长什么样（极简规范，自己够用就行）

不用学复杂标准，入门只需要这几类记号：

1. 变量：`sum ← 0` （sum初始化为0）
2. 分支：`if 条件 then ... else ... end if`
3. 循环：`while 条件 do ... end while` / `for i from 1 to n do ... end for`
4. 函数：`function f(x)`
5. 输出：`return / print`

> 
> 重点：伪代码**不能出现编程语言独有的东西**，比如 `vector`、`++`、`cout`。
> 
> ❌ 坏伪代码：`for(int i=0;i<n;i++) sum+=a[i];`（这就是C++代码，不是伪代码）
> 
> ✅ 好伪代码：
 ```text
sum ← 0
for i from 0 to n-1:
    sum ← sum + a[i]
end for
return sum
```

伪代码的本质：**剥离语法，只保留逻辑步骤**。

## 二、分阶段训练（循序渐进，从易到难，适合算法入门）

### 阶段1：代码 → 伪代码（逆向练习，1～2周）

任务：拿你已经AC的代码，盖住题目，**从代码反推出伪代码**。
目的：学会区分「逻辑」和「语法细节」。

练习步骤：

1. 拿出一段AC代码
2. 遮住代码，只看你写的伪代码，读一遍，确认：**不看代码，也能看懂要干什么**
3. 检查：如果伪代码里出现C++/Python语法，全部改成自然语言描述

示例：
C++代码：

```cpp
int maxn = a[0];
for(int i = 1; i < n; i++){
    if(a[i] > maxn) maxn = a[i];
}
```

你要写出伪代码：

```text
max_val ← a[0]
for i from 1 to n-1:
    if a[i] > max_val then
        max_val ← a[i]
    end if
end for
return max_val
```

✅ 验收标准：别人看不懂C++，但能看懂你的伪代码。

> 
> 这个阶段是热身：让你明白逻辑应该怎么表达。你现在擅长“伪代码转代码”，反过来练习，打通双向转换。

---

### 阶段2：读题 → 手写伪代码（核心训练，最重要）

做题流程**强制改成这个顺序，不许跳过**：

1. 读题，理解输入输出、约束条件、样例
2. **不看任何题解、别人的伪代码**，在草稿纸上回答这4个问题（中文草稿也行）
- 我需要保存哪些信息？（变量/状态）
- 有没有重复操作？适合用循环吗？循环什么时候停？
- 什么时候需要分支判断？
- 最终答案怎么得到？
3. 根据上面4个回答，翻译成伪代码
4. 写完伪代码，**拿样例手动模拟一遍伪代码**（非常关键！用纸手跑一遍变量变化）
> 很多逻辑bug，代码写出来才发现，但伪代码阶段模拟就能发现。
5. 伪代码验证无误 → 再翻译成代码提交
6. 做完后对照题解：对比你的伪代码和题解思路差异，不是对比代码。

> 
> 关键点：**允许你的伪代码和标准答案不一样，只要逻辑正确**。伪代码没有唯一正确版本。

举个简单例子：题目求数组最大值
你的中文草稿：

- 保存当前最大值，初始等于数组第一个元素
- 逐个遍历剩下元素，如果当前元素更大，更新最大值
- 遍历结束，输出最大值

转伪代码，然后手模拟样例：数组 `[3,1,5,2]`

- max_val=3
- i=1，a=1，不更新
- i=2，a=5，max_val=5
- i=3，a=2，不更新
最后答案5，正确。

---

### 阶段3：伪代码变形练习（训练迁移能力，防止死记思路）

同一道题，写完伪代码之后，**修改题目条件，改写伪代码**，不用写代码。
例：原题找数组最大值。
变体1：找最大值的下标 → 修改伪代码，增加记录下标变量
变体2：找第二大的值 → 修改更新逻辑

这个练习专门解决：记住了原题伪代码，换个问法就不会。

### 阶段4：口头伪代码（进阶，锻炼大脑直接建模）

不拿纸笔，读完题目，**口述伪代码**给自己听。
如果说不连贯、卡壳，说明思路还没成型，回到草稿纸上写。
这个训练对笔试、面试非常有用。

## 三、训练时的硬性规则（防止回到老习惯）

1. **没有伪代码，不写代码**。一旦发现自己直接上手写for/if，立刻停笔，强制写伪代码。
2. **禁止抄写别人的伪代码**。参考可以，但必须合上，独立重写。抄写只是记忆文本，不是建模。
3. **伪代码要能手动模拟**。如果你自己没法拿样例一步一步跑伪代码，说明伪代码写得含糊、逻辑不完整。
- ❌ 坏例子：`遍历数组，处理元素，更新答案`（太笼统，无法模拟）
- ✅ 好例子：每一步都明确变量怎么变。
4. 不要追求伪代码简洁。入门阶段，写长一点、啰嗦一点没关系，清晰优先。

## 四、常见坑

1. 把伪代码写成简化版代码：一堆`++`、数组下标语法，失去伪代码意义。
2. 跳过样例模拟：伪代码写了，但里面藏边界错误，等到写代码才暴露，浪费时间。
3. 伪代码只写主干，忽略边界情况（空数组、n=1等）。伪代码里必须包含边界处理。

## 五、每日训练计划（推荐）

- 每天 1～2 道算法入门题（枚举、模拟、双指针这类基础题最合适）
- 流程：读题 → 中文草稿 → 写伪代码 → 手模拟样例 → 转代码
- 每周选2道旧题，遮住题解，重新独立写伪代码复习
- 不追求刷题数量，优先保证每道题都走完这套流程
