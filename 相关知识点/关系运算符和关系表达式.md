## 关系运算符和关系表达式
### 关系运算符
关系运算符用于比较两个值，运算结果为布尔值（true或false）。
| 运算符 | 含义 | 优先级 |
| :---: | :---: | :---: |
| `==` | 等于 | 1 |
| `!=` | 不等于 | 1 |
| `>` | 大于 | 1 |
| `<` | 小于 | 1 |
| `>=` | 大于等于 | 1 |
| `<=` | 小于等于 | 1 |

### 关系表达式
关系表达式由关系运算符连接两个表达式构成，其运算结果为布尔值。
```cpp
int a = 1;
int b = 2;
bool c = a > b;
``` 
### 注意事项
1. 关系运算符的优先级低于算术运算符，高于赋值运算符。
2. 关系运算符的优先级高于逻辑运算符。
3. 关系运算符的优先级相同，按照从左到右的顺序进行计算。
4. 关系运算符的运算结果为布尔值，即true或false。

### 示例
```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    int b = 20;
    int c = 30;
    
    cout << (a > b) << endl;  // 输出0，即false
    cout << (a < b) << endl;  // 输出1，即true
    cout << (a == b) << endl; // 输出0，即false
    cout << (a != b) << endl; // 输出1，即true
    cout << (a >= b) << endl; // 输出0，即false
    cout << (a <= b) << endl; // 输出1，即true

    return 0;
}
```
