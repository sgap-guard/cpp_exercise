## C++循环语句
### 1.while循环
```cpp
while(表达式)
{
    语句
}
```
**while循环的执行流程：**
1. 先判断表达式是否为真，如果为真，则执行循环体，如果为假，则不执行循环体
2. 循环体执行完毕后，回到表达式处，继续判断表达式是否为真，如果为真，则继续执行循环体，如果为假，则结束循环
**while循环的注意事项：**
1. while循环的循环体至少执行一次
2. while循环的循环体可以是单条语句，也可以是多条语句
3. while循环的循环体可以是空语句
4. while循环的循环体中可以包含break语句，用于提前结束循环
5. while循环的循环体中可以包含continue语句，用于跳过本次循环，继续下一次循环
6. while循环的循环体中可以包含goto语句，用于跳转到循环体的其他位置
7. while循环的循环体中可以包含return语句，用于返回函数

### 3.for循环
```cpp
for(表达式1;表达式2;表达式3)
{
    语句
}
```
**for循环的执行流程：**
1. 先执行表达式1，然后判断表达式2是否为真，如果为真，则执行循环体，如果为假，则结束循环
2. 循环体执行完毕后，执行表达式3，然后回到表达式2处，继续判断表达式2是否为真，如果为真，则继续执行循环体，如果为假，则结束循环
**for循环的注意事项：**
1. for循环的循环体至少执行一次
2. for循环的循环体可以是单条语句，也可以是多条语句
3. for循环的循环体可以是空语句
4. for循环的循环体中可以包含break语句，用于提前结束循环
5. for循环的循环体中可以包含continue语句，用于跳过本次循环，继续下一次循环
6. for循环的循环体中可以包含goto语句，用于跳转到循环体的其他位置
7. for循环的循环体中可以包含return语句，用于返回函数

### 4.循环嵌套
循环嵌套是指在循环体中再嵌套一个循环，例如：
```cpp
for(int i=0;i<10;i++)
{
    for(int j=0;j<10;j++)
    {
        //循环体
    }
}
```
**循环嵌套的注意事项：**
1. 循环嵌套的循环体中可以包含break语句，用于提前结束循环
2. 循环嵌套的循环体中可以包含continue语句，用于跳过本次循环，继续下一次循环
3. 循环嵌套的循环体中可以包含goto语句，用于跳转到循环体的其他位置
4. 循环嵌套的循环体中可以包含return语句，用于返回函数

### 5.循环控制语句
循环控制语句用于控制循环的执行，包括break、continue和goto语句。
1. break语句用于提前结束循环，例如：
```cpp
for(int i=0;i<10;i++)
{
    if(i==5)
    {
        break;
    }
    //循环体
}
```
2. continue语句用于跳过本次循环，继续下一次循环，例如：
```cpp
for(int i=0;i<10;i++)
{
    if(i==5)
    {
        continue;
    }
    //循环体
}
```
3. goto语句用于跳转到循环体的其他位置，例如：
```cpp
for(int i=0;i<10;i++)
{
    if(i==5)
    {
        goto end;
    }
    //循环体
end:
    //跳转后的代码
}
```
**循环控制语句的注意事项：**
1. break语句只能用于循环体中，不能用于循环体外的语句
2. continue语句只能用于循环体中，不能用于循环体外的语句
3. goto语句只能用于循环体中，不能用于循环体外的语句
4. break语句和continue语句只能用于循环体中，不能用于循环体外的语句
