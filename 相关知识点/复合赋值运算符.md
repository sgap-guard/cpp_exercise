## 复合赋值运算符
复合赋值运算符就是将算术运算符和赋值运算符结合在一起，形成的新运算符。复合赋值运算符的格式为：

| 运算符 | 作用 |
| --- | --- |
| `+=` | 加法赋值运算符 |
| `-=` | 减法赋值运算符 |
| `*=` | 乘法赋值运算符 |
| `/=` | 除法赋值运算符 |
| `%=` | 取模赋值运算符 |
| `<<=` | 左移赋值运算符 |
| `>>=` | 右移赋值运算符 |
| `&=` | 按位与赋值运算符 |
| `\|=` | 按位或赋值运算符 |
| `^=` | 按位异或赋值运算符 |
| `**=` | 指数赋值运算符 |


复合赋值运算符的作用是将变量与表达式进行运算，并将结果赋值给变量。例如：

```c
int a = 10;
a += 5; // 等价于 a = a + 5;
```
上述代码中，变量a的值被赋值为15。

复合赋值运算符的优先级与赋值运算符相同，都是最低的。在复合赋值运算符中，先进行运算，然后再进行赋值。例如：

```c
int a = 10;
a += 5 * 2; // 等价于 a = a + 5 * 2;
```
上述代码中，变量a的值被赋值为20。
