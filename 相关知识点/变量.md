## 变量

变量是指在程序运行时可以改变的值，用于存储数据。

### 变量的声明定义

变量的声明定义需要在程序中使用`typedef`语句或直接在程序中定义。

### 变量的使用

变量的使用需要在程序中使用变量的名称即可。

```cpp
int a = 10;
int b = a + 5;
```

### 变量的作用域

变量的作用域是指变量在程序中的可见范围。根据变量的作用域，可以将变量分为全局变量和局部变量。

#### 全局变量

全局变量在整个程序中都是可见的，可以在程序的任何地方使用。全局变量的声明定义需要在函数外部进行。

#### 局部变量

局部变量只在函数内部可见，不能在函数外部使用。局部变量的声明定义需要在函数内部进行。

### 变量的命名规则

变量的命名规则需要遵循以下规则：

1. 变量名只能由字母、数字和下划线组成，且不能以数字开头。
2. 变量名区分大小写。
3. 变量名不能与关键字冲突。
4. 变量名应具有一定的意义，以便于理解和维护程序。

### 变量的类型

变量的类型是指变量可以存储的数据类型。根据变量的类型，可以将变量分为整型、浮点型、字符型等。

#### 整型

整型变量可以存储整数，包括有符号整数和无符号整数。常见的整型有`int`、`short`、`long`等。

| 类型                   | 字节  | 范围                                         |
| -------------------- | --- | ------------------------------------------ |
| `int`                | 4   | -2147483648 ~ 2147483647                   |
| `short`              | 2   | -32768 ~ 32767                             |
| `long`               | 4   | -2147483648 ~ 2147483647                   |
| `long long`          | 8   | -9223372036854775808 ~ 9223372036854775807 |
| `unsigned int`       | 4   | 0 ~ 2147483647                             |
| `unsigned short`     | 2   | 0 ~ 65535                                  |
| `unsigned long`      | 4   | 0 ~ 4294967295                             |
| `unsigned long long` | 8   | 0 ~ 184467440737095516156                  |

#### 浮点型

浮点型变量可以存储小数，包括单精度浮点数和双精度浮点数。常见的浮点型有`float`、`double`等。

| 类型            | 字节  | 范围                                                 |
| ------------- | --- | -------------------------------------------------- |
| `float`       | 4   | -3.4028234663852886E+38 ~ 3.4028234663852886E+38   |
| `double`      | 8   | -1.7976931348623157E+308 ~ 1.7976931348623157E+308 |
| `long double` | 16  | -1.189231348623157E+308 ~ 1.189231348623157E+308   |

#### 字符型

字符型变量可以存储单个字符，包括`char`类型。

```cpp
char a = 'a';
```

### 变量的初始化

变量的初始化是指在声明变量时为其赋初值。变量的初始化可以在声明时进行，也可以在程序中使用赋值语句进行。

#### 声明时初始化

声明时初始化是指在声明变量时为其赋初值。在声明时初始化的变量，其值在程序运行时是确定的，不能在程序中被修改。

```cpp
int a = 10;
```

#### 赋值语句初始化

赋值语句初始化是指在程序中使用赋值语句为变量赋值。在赋值语句初始化的变量，其值在程序运行时是可以改变的。

```cpp
int a;
cin >> a;
```

### 变量的赋值

变量的赋值是指在程序中使用赋值语句为变量赋值。变量的赋值可以在声明时进行，也可以在程序中使用赋值语句进行。

#### 声明时赋值

声明时赋值是指在声明变量时为其赋初值。在声明时赋值的变量，其值在程序运行时是确定的，不能在程序中被修改。

```c
int a = 10;
```

#### 赋值语句赋值

赋值语句赋值是指在程序中使用赋值语句为变量赋值。在赋值语句赋值的变量，其值在程序运行时是可以改变的。

```cpp
int a;
cin >> a;
```

### 变量的引用

变量的引用是指在程序中使用变量的名称来访问变量的值。变量的引用可以在程序中的任何地方进行。

#### 全局变量引用

全局变量引用是指在程序中使用全局变量的名称来访问全局变量的值。全局变量引用可以在程序的任何地方进行。

```cpp
int a = 10;
int b = a + 5;
```

#### 局部变量引用

局部变量引用是指在程序中使用局部变量的名称来访问局部变量的值。局部变量引用只能在函数内部进行。

```cpp
int a = 10;
int b = a + 5;
```
