# C++ 使用字符串存储高精度数字

> 
> 核心：**C++ 原生没有高精度整数/浮点数类型，可以用 std::string 保存数字的字符形式，手动实现加减乘除运算**，这是手写高精度最常见方案。

## 基本原理

把数字当成一串字符，例如 `"123456789012345678901234567890"`，每一位字符单独存取：

```
std::string num = "123456789012345678901234567890";
```

字符 `'0'`~`'9'`，计算时：`digit = num[i] - '0'` 转成数值。

## ✅ 可用场景

1. **超大整数**：超过 `unsigned long long`（上限约 $1.8\times10^{19}$）的整数，比如几百位、上千位大整数，做加减、高精度乘法、模运算。
2. **竞赛高精度题**：大整数加法、大整数阶乘、大整数斐波那契。
3. **需要保留全部十进制有效位**，不能用 double（double 只有约15~17位有效数字）。

## ❌ 限制点（非常关键）

1. **没有原生运算符支持**
 `string` 只是字符串，不能直接写 `a + b`、`a * b`，必须自己手写逐位运算函数、处理进位/借位。```
std::string a = "123", b = "456";
// a + b 是字符串拼接，不是数字相加！
std::string c = a + b; // c = "123456"，不是 "579"
```
2. **浮点数高精度实现更麻烦**
 字符串存小数要单独处理小数点位置，对齐小数位，进位逻辑比整数复杂很多。
3. **性能较差**
 每一位都是字符操作，循环多；位数越大，乘法复杂度越高（朴素乘法 $O(n^2)$），上万位以上速度会明显变慢。
4. **负号需要额外处理**
 需要单独标记正负，减法要比较大小、处理结果符号。
5. **输入输出要保证格式合法**
 需要校验字符串：不能包含字母、多余前导零（可写函数去除前导零）、多个小数点。
6. **不能直接转为内置数字类型**
 一旦位数超过内置类型上限，`stoll` / `atoi` 会直接溢出报错。

## 最简示例：高精度大整数加法

```
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

string add(string a, string b) {
    string res;
    int carry = 0;
    reverse(a.begin(), a.end());
    reverse(b.begin(), b.end());
    for (int i = 0; i < a.size() || i < b.size() || carry; i++) {
        int da = i < a.size() ? a[i] - '0' : 0;
        int db = i < b.size() ? b[i] - '0' : 0;
        int sum = da + db + carry;
        carry = sum / 10;
        res.push_back(sum % 10 + '0');
    }
    reverse(res.begin(), res.end());
    return res;
}

int main() {
    string s1 = "12345678901234567890";
    string s2 = "98765432109876543210";
    cout << add(s1, s2) << endl;
    return 0;
}
```

## 替代方案补充

- 手写字符串高精度：适合算法竞赛，几百～几千位。
- 第三方库：GMP、BigInt 库，适合工程，位数极大。
- C++23 也没有内置 big integer。
