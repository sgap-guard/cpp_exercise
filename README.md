### 项目介绍
这是维护者sgap学习和练习C++语言的练习题项目，将会在维护者每做完一定数量的题目后，推送到项目中。项目中的代码使用了C++23标准，并且尽量遵循了良好的编程规范。

### 使用说明
1. 题目来源于洛谷以及VJudge等其他平台，题目编号遵从原网站的编号，未做任何修改。
2. 本项目含有题目以及标准cpp答案，你可以按照目录索引找到他们。
3. 本项目中的已有代码都是在本地编译通过的，你可以直接在本地运行。
4. 本项目中的代码都是开源的，你可以自由地使用和修改，并根据需要添加到项目中。
5. 本项目中的代码都是在GitCode仓库中，你可以直接在GitCode仓库中查看和贡献。
6. 受限于时间与精力，有些cpp源文件未附上原题目以及注释、标准cpp答案等，你可以根据需要添加到项目中。
7. 受限于维护者做题平台的不全面，本项目不可能覆盖所有题目，包括但不限于：洛谷、VJudge等平台的题目，以及由他们衍生出来的题目。
8. 本项目仍含有一些未解出的题目以及未上传的题目，你可以根据需要添加到项目中。
9. 本项目亦含有一些相关知识点，但不是很全面，你可以根据需要添加到项目中。
10. 欢迎您在issues或Pull Request中提交您的贡献，包括但不限于：
    - 新增题目
    - 修复错误
    - 优化代码
    - 新增或改正知识点
11. 所有文件的代码页面均遵循UTF-8编码，请确保你的编辑器支持UTF-8编码。
12. 本地所有代码均在Windows11上编译通过，不能确保在其他操作系统上编译通过。
13. 如果您也有您自己的学习经验或知识点，欢迎您在Pull Request中提交您的学习经验。您的学习经验将被添加到项目中，帮助其他学习者。
14. 如果您也有您自己学习C/C++的题目仓库，欢迎共享您的题目仓库。您的题目仓库将会作为友链将被添加到项目中，帮助其他学习者。

### 注意事项
- 无论你是业界大佬还是初学者，我们都欢迎你提交Pull Request。
- 请确保你的代码遵循了良好的编程规范，符合**C++23标准**，并且**没有语法错误，也没有逻辑错误**。
- 请在提交Pull Request之前，附上你的代码的**详细描述**，包括你添加的题目（`md`格式）、修改的代码（`cpp`格式）等。
- 请在提交Pull Request之前，确保你的代码已经在您的操作系统上（包括但不限于Windows、Linux、macOS等）**通过了编译和测试，且可以在本地运行通过**。
- 请在提交Pull Request时，注意**代码的格式和缩进**，确保与项目中的代码保持一致。
- 请在提交Pull Request时，注意**文件的命名规范**，要求文件名与题目编号一致。
- 欢迎您给出如何写出这段代码的提示，以便项目维护者了解你的代码。
- 如果可以，欢迎您在代码中添加注释，说明代码的功能和实现原理。
- 如果可以，欢迎您在代码中添加测试用例，以便项目维护者了解你的代码。
- 如果可以，欢迎提供您在学习过程中遇到的困难和解决方案，以便项目维护者了解你的学习过程并帮助到其他学习者。
- 请在提交Pull Request时，在commit message中，说明你**贡献题目的来源及题目编号或者是您的原创题目**，以便项目维护者了解你的改动。
- 如果是您的原创题目（包括但不限于是通过AI生成的题目），确保你的题目无歧义，易于理解，不会与已有的题目冲突。
- 本项目**只接受与C++23标准相关的贡献**，不接受与C++17、C++14等旧版本相关的贡献。
- 本项目**只接受C/C++代码**，不接受其他语言的代码，如Python、Java等。
- 本项目**不接受任何形式的广告或推广**，包括但不限于在代码中插入广告、在代码中插入推广链接等。
- 本项目**不接受任何形式的恶意攻击或破坏**，包括但不限于在代码中插入恶意代码、在代码中插入恶意链接等。
- 受限于维护者的时间和精力，**您的贡献可能会被延迟处理**，我们会在收到您的贡献后尽快进行审核。
- 通过AI生成的题目，需要附上您的提示词，以便项目维护者了解您的代码。
