### 项目介绍
这是维护者sgap学习和练习C++语言的练习题项目，将会在维护者每做完一定数量的题目后，推送到项目中。项目中的代码在无特殊要求下，均使用了C++26标准，并且尽量遵循了良好的编程规范。

如果OJ平台上**特别要求使用C++11标准**，将会特殊说明在题目中。例如：
```
// 这是一个C++11标准的题目
```

### 使用说明
1. 题目来源于洛谷以及VJudge等多个平台，题目编号遵从原网站的编号，未做任何修改。
2. 本项目含有题目以及`cpp`答案（可能包含**错误**的`cpp`答案），你可以按照目录索引找到他们。
3. 本项目中的已有代码都是在本地编译通过的，你可以直接在本地运行。
4. 本项目中的代码都是开源的，你可以自由地使用和修改，并根据需要添加到项目中。
5. 本项目中的代码托管在[GitCode](https://gitcode.com/sgap_guard/cpp_exercise)、[Gitee](https://gitee.com/sgap_guard/cpp_exercise)仓库中，将以GitCode作为主仓库，Gitee作为镜像仓库，你可以直接在上述仓库中查看，在GitCode贡献。
6. 由于主仓库是GitCode仓库，Gitee仓库是镜像，所以Gitee仓库不包含任何贡献。而且镜像仓库的同步没有主仓库同步及时，所以Gitee仓库不会及时更新，可能会导致代码不一致。
7. 受限于时间与精力，有些`cpp`源文件未附上原题目以及注释、标准`cpp`答案等，你可以根据需要添加到项目中。
8. 受限于维护者做题平台的不全面，本项目不可能覆盖所有题目，包括但不限于：洛谷、VJudge等平台的题目，以及由他们衍生出来的题目。
9.  本项目仍含有一些未解出的题目以及未上传的题目，你可以根据需要添加到项目中。
10. 本项目亦含有一些相关知识点，但不是很全面，你可以根据需要添加到项目中。
11. 欢迎您在issues或Pull Request中提交您的贡献，包括但不限于：
    - 新增题目
    - 修复错误
    - 优化代码
    - 新增或改正知识点
12. 所有文件的代码页面均遵循`UTF-8`（不含中文）编码，请确保你的编辑器支持`UTF-8`编码。含有中文的源代码均采用`GBK`编码。
13. 本地所有代码均在`Windows 11`上编译通过，不能确保在其他操作系统上编译通过。
14. 如果您也有您自己的学习经验或知识点，欢迎您在Pull Request中提交您的学习经验。您的学习经验将被添加到项目中，帮助其他学习者。
15. 如果您也有您自己学习C/C++的题目仓库，欢迎共享您的题目仓库。您的题目仓库将会作为友链将被添加到项目中，帮助其他学习者。

### 注意事项
1. 无论你是业界大佬还是初学者，我们都欢迎你提交Pull Request。
2. 请确保你的代码遵循了良好的编程规范，符合**C++26标准**（或**C++11标准**，有特殊要求的题目），并且**没有语法错误，也没有逻辑错误**。
3. 请确保你提交的代码的时间复杂度与空间复杂度符合题目要求。
4.  请在提交Pull Request之前，附上你的代码的**详细描述**，包括你添加的题目（`md`格式）、修改的代码（`cpp`格式）等。
5.  请在提交Pull Request之前，确保你的代码已经在您的操作系统上（包括但不限于`Windows`、`Linux`、`macOS`等）**通过了编译和测试，且可以在本地运行`通过**。
6. 请在提交Pull Request时，注意**代码的格式和缩进**，确保与项目中的代码保持一致。
7. 请在提交Pull Request时，注意**文件的命名规范**，要求文件名与题目编号一致。
8. 欢迎您给出如何写出这段代码的提示，以便项目维护者了解你的代码。
9. 如果可以，欢迎您在代码中添加注释，说明代码的功能和实现原理。
10. 如果可以，欢迎您在代码中添加测试用例，以便项目维护者了解你的代码。
11. 如果可以，欢迎提供您在学习过程中遇到的困难和解决方案，以便项目维护者了解你的学习过程并帮助到其他学习者。
12. 请在提交Pull Request时，在commit message中，说明你**贡献题目的来源及题目编号或者是您的原创题目**，以便项目维护者了解你的改动。
13. 如果是您的原创题目（包括但不限于是通过AI生成的题目），确保你的题目无歧义，易于理解，不会与已有的题目冲突。
14. 本项目**只接受与C++11或者C++26标准相关的贡献**，不接受其他标准等相关的贡献。
15. 本项目**只接受C++代码**，不接受其他语言的代码，如Python、Java等。
16. 本项目**不接受任何形式的广告或推广**，包括但不限于在代码中插入广告、在代码中插入推广链接等。
17. 本项目**不接受任何形式的恶意攻击或破坏**，包括但不限于在代码中插入恶意代码、在代码中插入恶意链接等。
18. 受限于维护者的时间和精力，**您的贡献可能会被延迟处理**，我们会在收到您的贡献后尽快进行审核。
19. 如果您通过AI生成的题目，需要附上您的提示词，以便项目维护者了解您的代码。
