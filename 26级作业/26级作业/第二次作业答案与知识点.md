## 相关知识点
### 一、直接回答

因为**默认的 `cout` 输出格式**和**题目要求的格式**不一样。不加 `fixed << setprecision(6)` 时，`double` 的输出可能：

1. **小数位数不固定**（可能是 3 位、6 位、或者科学计数法）。
2. **可能输出科学计数法**（如 `5.68e+01`）。
3. **精度不够**（默认只输出 6 位有效数字，而不是 6 位小数）。

题目要求输出double类型的数，所以必须用 `fixed << setprecision(6)`。

### 二、用样例说明

输入：
```text
1 B 13 56.8
```

**不加 `fixed << setprecision(6)`**：
```cpp
cout << c << endl;
```
输出：
```text
56.8
```

**加 `fixed << setprecision(6)`**：
```cpp
cout << fixed << setprecision(6) << c << endl;
```
输出：
```text
56.800000
```

题目要求的是double类型的数，所以必须加。

### 三、`fixed` 和 `setprecision` 的作用

#### 1. `setprecision(n)`

- **不加 `fixed`**：设置**有效数字**的位数。例如 `setprecision(6)` 表示总共输出 6 位有效数字。
  - `56.8` → `56.8`（3 位有效数字）
  - `3.14159265` → `3.14159`（6 位有效数字）

- **加 `fixed`**：设置**小数点后**的位数。例如 `fixed << setprecision(6)` 表示小数点后固定 6 位。
  - `56.8` → `56.800000`
  - `3.14159265` → `3.141593`

#### 2. `fixed`

- 强制使用**定点表示法**（非科学计数法）。
- 与 `setprecision(n)` 配合时，表示**小数点后 n 位**。

### 四、为什么默认输出不是固定 6 位？

C++ 默认的 `cout` 行为：
- 使用**默认精度**（6 位有效数字）。
- 如果数值很大或很小，自动切换为**科学计数法**。
- 不保证小数位数固定。

例如：
```cpp
double a = 123456789.123456;
cout << a << endl;   // 输出 1.23457e+08
```

**科学计数法**显然不符合题目要求。

### 五、题目为什么要求固定 6 位？

因为题目要考察：
1. **浮点数的输出格式控制**。
2. **`fixed` 和 `setprecision` 的用法**。

在竞赛中，浮点数输出通常要求**固定小数位数**，避免因精度问题导致 WA。

### 六、总结

| 写法 | 含义 | 输出示例（c = 56.8） |
|------|------|----------------------|
| `cout << c` | 默认精度 | `56.8` |
| `cout << setprecision(6) << c` | 6 位有效数字 | `56.8` |
| `cout << fixed << setprecision(6) << c` | 小数点后 6 位 | `56.800000` |
| `cout << scientific << setprecision(6) << c` | 科学计数法，6 位小数 | `5.680000e+01` |

**总结**：题目要求输出**固定 6 位小数**，所以必须用 `fixed << setprecision(6)`。不加的话，`cout` 默认只输出 6 位有效数字，小数位数不固定，甚至可能输出科学计数法，导致格式错误（WA）。这是浮点数输出的标准写法，竞赛中遇到浮点数输出几乎都要加。
